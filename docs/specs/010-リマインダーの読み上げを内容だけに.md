# 010 リマインダーの読み上げを内容だけに

- 状態：完了
- 依存：004

## 👤 ユーザーが確認するところ

### 何のための機能か
いまは時刻になると「〇〇の時間です」と読み上げるので、「洗濯物を取り込んで」のような言い方を登録すると「洗濯物を取り込んでの時間です」になってしまう。登録した言葉をそのまま読み上げるようにして、知らせ方を自由に決められるようにします。

### できるようになること
- 時刻になったら、登録した内容**だけ**を読み上げる
  - 例：「ゴミ出しの時間です」と登録 →「ゴミ出しの時間です」
  - 例：「洗濯物を取り込んで」と登録 →「洗濯物を取り込んで」
  - すでに「ゴミ出し」と登録してあるものは、「ゴミ出し」とだけ読み上げる
- 同じ時刻に2つ以上あるときは、順番に読み上げる（例：「ゴミ出しの時間です。洗濯物を取り込んで。」）
- 端末がつながっていなくて遅れたときは、今までどおり「遅れてお知らせします」を先に付ける（例：「遅れてお知らせします。洗濯物を取り込んで。」）
- 声で登録するとき、アイリスは、言われた言い方をなるべくそのまま内容にする
  - 例：「6時に『お風呂を沸かして』ってリマインダーして」→ 内容は「お風呂を沸かして」
- 確認画面のリマインダーの内容の欄も、そのまま読み上げられる言葉として扱う（画面の動きは変わらない）

### 使い方の流れ
1. 「アイリス、明日の朝7時に『燃えるゴミの日だよ』ってリマインダーして」
2. 翌朝7時に、チャイムのあと「燃えるゴミの日だよ」と読み上げる。

### やらないこと
- 読み上げの声や速さを、リマインダーごとに変えること
- 登録済みのリマインダーの内容を、自動で書き換えること（「ゴミ出し」のままでよければそのまま。変えたいときは確認画面か声で直す）

### チャットで決めたこと
| 決めたこと | 理由 |
|---|---|
| 「〇〇の時間です」を付けず、登録した内容だけを読み上げる | 内容を柔軟に変えられるようにするため（ユーザーの要望） |
| 遅れたときの「遅れてお知らせします」は残す | 時刻を過ぎていることが分からないと、勘違いするため |

### ユーザーにお願いすること
- 実装前に準備するもの：なし
- 完成後に手で確認するもの
  - 実機で、登録した言葉どおりに読み上げられる（聞こえ方は機械では判定できないため）
