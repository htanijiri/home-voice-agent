# home-voice-agent

M5Stack の AtomS3R と Voice Pyramid を組み合わせて作る、家庭用の音声 AI スマートスピーカーです。
リビングに置き、家族が「アイリス」と呼びかけて日本語で話しかけると、クラウドの LLM（Claude）が考えた返事を音声で返します。
買い物リストとリマインダーを音声で操作でき、スマホのブラウザからも確認・修正できます。

## 設計の前提（なぜこの作りか）
- **今使っている Alexa の主な用途（買い物リスト・リマインダー）を確実に置き換える**ことが目標です。Alexa の全機能との互換は目指しません。
- **家にパソコンを常時起動しておかなくても動く**ようにします。端末は、クラウド（Fly.io 東京）に置いたサーバーと直接話します。
- **端末側は、M5Stack 公式の Xiaozhi ファームウェアを使います**。中身をゼロから作らず、接続先と言語、ウェイクワードを設定してビルドします。
- 会話・ツール実行・データ管理は端末から切り離しているので、将来は別の端末（スタックチャンなど）からも同じサーバーを使えます。
- プライバシー：
  - ウェイクワードは端末の中で判定するので、呼びかける前の音声はクラウドに送りません。
  - 録音した音声は保存せず、文字にした会話記録も30日で自動削除します。
  - API キーは端末に入れません。
- あえてやらないこと（今回）：
  - 独自のウェイクワードの学習
  - 話者の識別
  - カレンダー、家電操作、センサー
  - 長期記憶
  - スタックチャンへの展開
  - 祖父母向けの見守り機能

詳しい経緯は [docs/HISTORY.md](docs/HISTORY.md) を参照してください。

## 主な機能
- 呼びかけ（アイリス）や画面のボタンで話し始め、日本語で雑談・質問ができる
- 返事のあとは、呼びかけ直さずに続けて話せる（しばらく黙ると待機に戻る）
- 状態（聞き取り中・考え中・話し中・エラー・マイクオフ）を、画面と LED で表示する
- 買い物リストを音声で操作できる（追加・読み上げ・削除・買った）
- リマインダーを音声で操作できる（登録・確認・変更・削除）。一回限りと繰り返しに対応し、時刻になったら読み上げる
- スマホのブラウザで、買い物リストとリマインダーを確認・修正できる（家族の Google アカウントでログイン）
- スマホで入力した文章を、アイリスがチャイムのあとに読み上げる
- 「アイリス、パパに連絡して」と話すと、用件が確認画面の「連絡」タブに届き、スマホに通知される（Web Push）
- 夜間は自動で音量を下げる。声で音量を変えられる

## 構成
```
[AtomS3R + Voice Pyramid（リビング）]
   │ ウェイクワード判定・録音・再生・画面と LED（Xiaozhi ファームウェア）
   │
   └─(インターネット・暗号化)─ [サーバー（Fly.io 東京）]
                                 ├─ 音声認識・音声合成（Google Cloud）
                                 ├─ 会話（Claude Haiku）＋ツール（買い物リスト・リマインダー）
                                 ├─ リマインダーのスケジューラー
                                 ├─ データ（SQLite）
                                 └─ 確認画面（Web・Google ログイン）
```

## セットアップ
1. アカウントと秘密情報を用意する：[docs/SETUP_ACCOUNTS.md](docs/SETUP_ACCOUNTS.md)
2. サーバー（Node.js 24 以上）

```bash
cd server && npm install && cp .env.example .env && cp config/config.example.toml config/config.toml
```

   `.env` に秘密情報を、`config/config.toml` に Mac の LAN 内アドレスなどを書いてから `npm run dev` で起動する。
3. ファームウェア：[firmware/README.md](firmware/README.md)（ESP-IDF v6.1 でビルドして USB で書き込む）
4. 端末の画面に6桁の番号が出たら、確認画面（`http://<Mac のアドレス>:8080/`）か `npm run device:approve -- <番号>` で承認する。
